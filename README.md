# Algorithm Explorer

## Project Overview

Algorithm Explorer is a group project for **CSC2107: Design and Analysis of Algorithms** at Uganda Christian University (UCU).

The project involves developing an interactive application with a graphical or web interface that allows users to enter their own inputs, run algorithms, and observe the results. The application demonstrates algorithm execution by displaying the output, execution steps, number of operations, and running time.

The project covers recursion, data structures, sorting algorithms, and time complexity analysis.

## Project Objectives

- Implement and demonstrate algorithms and data structures.
- Allow users to provide custom inputs and observe algorithm execution.
- Display algorithm results, execution steps, operation counts, and running times.
- Demonstrate recursion, sorting, data structures, and time complexity analysis.
- Strengthen practical understanding of algorithm design and analysis.

## Key Features

The application is intended to provide:

- **Custom Input:** Users can enter their own data.
- **Algorithm Execution:** Algorithms process the supplied input.
- **Step-by-Step Demonstration:** Users can observe the steps taken during execution.
- **Operation Counting:** The application displays the number of operations performed.
- **Running-Time Measurement:** The application displays the time taken to execute an algorithm.
- **Interactive Interface:** Results are presented through a graphical or web interface.

## Implementation Requirements

All algorithms and data structures must be implemented from scratch.

The project must not use:

- Built-in sorting functions.
- Ready-made stack classes.
- Ready-made queue classes.
- Ready-made list classes.

The implementation must demonstrate the underlying logic and execution process of the algorithms and data structures.

Additional restrictions apply to groups using Python, as stated in the project requirements.
